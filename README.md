# 主动发消息 · qq-bridge 插件

> v1.1：窗口改为「桥启动 → 桥关闭」，间隔默认 60 分钟，规则见下。

## 规则

每次提醒由 Agent 自己决定：

- ① 向好友或群主动发消息（任何好友/群，不看白名单）
- ② 发空间说说 / 刷好友动态

判定：
- 两件都不做 → 本轮结束，算完成
- 只做一件 → 自己挑
- 两件都做 → **先说/空间，再发消息**（优先级）

## 时间窗口

- **起点**：桥启动（= 阿扎被接起）
- **终点**：桥关闭（= 阿扎停止）
- 期间每 `intervalMinutes`（默认 60）提醒一次
- 若触发时 Agent 正在跑别的回合：本次立即结束，等那个回合完成**立刻补发一次**
